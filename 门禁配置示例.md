# 门禁配置示例（与出厂默认同步）

> 本文件是 `app/default_phase_gate_config.go` 中 `defaultPhaseGateConfig` 的镜像，首次启动时写入 app_config。
> **权威源是 .go 文件**：修改门禁默认配置时先改 .go，再把 `<!-- phase-gate-config -->` 块原样同步到这里。
> tools 支持类别简写（get/create/update/delete/search/remove/web/check），运行时自动展开为对应前缀工具。
> 用户已改过的配置存 DB，不会被出厂默认覆盖；设置页可"恢复出厂默认"。

<!-- 批量模式使用建议（cacheprobe 模拟验证，2026-08-09，DeepSeek 价 0.02/1/2）：
- 批量章数建议 5-10 章/批：批内越大越省（prepare/outline 技能/review/maintain 固定成本摊薄），
  3 章是最贵档（¥0.119/章）；上限受上下文窗口/压缩点约束
- 批内每 3 章自检一次（三章一轮，白金作者方法论）：write 循环第 3/6/9 章后插入批次自检
  （技术自检 + AI 指纹扫描 + 修复），成本 +0.3% 几乎免费（自检落在历史厚处，前缀命中）
- 不要拆成多批：批次边界有新窗口成本（2批×3章 ¥0.112/章 比 单批6章 ¥0.090/章 贵 24%）
- 批量对比：单批5章 ¥0.092/章 vs 单章5轮 ¥0.275/章（省 66%）；批量短板是第 2-N 章无审稿，
  用三章一轮自检补齐质量节奏 -->
