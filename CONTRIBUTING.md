# Contributing

感谢你对 Goink 的关注！

> **特别说明**：本项目的维护者不是程序员，所有代码修改由 AI 完成。
> 这意味着我们可能响应较慢，但每个 Issue 和 PR 都会被认真对待。

## 如何贡献

### 报告 Bug

使用 [Bug Report](https://github.com/HeRockOne/goink/issues/new?template=bug_report.md) 模板。

请提供：
- 复现步骤
- 期望行为 vs 实际行为
- 环境信息（OS、Goink 版本、LLM 模型）
- 日志（如有）

### 提出功能

使用 [Feature Request](https://github.com/HeRockOne/goink/issues/new?template=feature_request.md) 模板。

### 贡献 Skill

使用 [Skill Contribution](https://github.com/HeRockOne/goink/issues/new?template=skill_contribution.md) 模板。

把你的写作方法论变成 `.md` 文件，提交 PR 或直接贴在 Issue 里。

### 提交 PR

欢迎提交 PR！但请注意：

1. **先开 Issue 讨论** — 避免做了大量工作后被拒绝
2. **保持小 PR** — 一个 PR 解决一个问题
3. **英文 commit** — 具体描述改了什么
4. **不要改 `models.ts`** — 这是 Wails 自动生成的

## 关于 AI 代码

本项目所有代码由 AI 编写。如果你发现代码有问题，欢迎提 Issue。
我们不保证代码质量，但保证每个问题都会被认真对待。

# Contributing

Thanks for your interest in Goink!

> **Note**: The maintainer is not a programmer. All code changes are made by AI.
> This means responses may be slow, but every Issue and PR will be taken seriously.

## How to Contribute

### Report Bugs

Use the [Bug Report](https://github.com/HeRockOne/goink/issues/new?template=bug_report.md) template.

### Request Features

Use the [Feature Request](https://github.com/HeRockOne/goink/issues/new?template=feature_request.md) template.

### Contribute Skills

Use the [Skill Contribution](https://github.com/HeRockOne/goink/issues/new?template=skill_contribution.md) template.

### Submit PRs

1. **Open an Issue first** — avoid wasted effort
2. **Keep PRs small** — one problem per PR
3. **English commits** — describe what changed
4. **Don't edit `models.ts`** — auto-generated by Wails

## About AI Code

All code in this project is written by AI. If you find issues, please report them.
We don't guarantee code quality, but we guarantee every problem will be taken seriously.
