# 玄幻/仙侠类型特化

判断准则：玄幻的核心是"升级绝对化"——一切围绕主角突破下一个境界展开。升级不是目的，是读者情绪的节拍器。每突破一次，给读者一次"变强了"的满足感。

## 修炼体系设计

### 境界划分原则

| 原则 | 说明 | ✅ 正例 | ❌ 反例 |
|------|------|---------|---------|
| 等级森严 | 每级有明确战力差距、寿元提升、新能力解锁 | 炼气(感知灵气)→筑基(御剑飞行)→金丹(炼丹)→元婴(分神多线) | 只写等级名，没有能力质变 |
| 突破有难度 | 每次突破需要特定条件，不能纯积累 | 需要心境考验/战斗经验/道之谜题/天材地宝 | 灵气够了就突破，毫无阻力 |
| 代价可见 | 越阶使用力量必有代价 | 禁术反噬、境界不稳、寿元消耗 | 无限越级无副作用 |

### 境界命名参考（可差异化）

传统体系：炼气→筑基→金丹→元婴→化神→合体→大乘→渡劫

差异化方向：
- **记忆体系**：记忆碎片→历史回响→因果追溯→天道记忆
- **职业体系**：学徒→匠师→大师→宗师→传奇（适用于炼器/炼丹专精）
- **血脉体系**：觉醒→凝脉→化龙→真灵→神裔

核心：**每个境界必须有独特的叙事功能**，不是为了打架更狠，而是为了解锁新玩法（探索秘境/跨地图移动/多线叙事/穿越位面）。

## 换地图节奏

### 莲花地图法（推荐）

主角主要活跃于"莲心"中心地图，剧情发展到瓶颈时去"莲花花瓣"走一圈获得收获，再回莲心推进主线。避免直接抛弃整张地图和人际关系。

### 换地图铁律

1. **提前铺垫人际关系**：去下一个地图前，先让下一个地图的人过来接触主角，把人际关系铺出去，主角再有充分理由过去
2. **地图与等级挂钩**：每张地图的最高等级者，是主角目前未达到但不比主角高出太多的级别
3. **换地图不掉追订**：换地图=掉追订，换小地图（县→郡→府→州→王都）比换大地图（飞升到新世界）损失小
4. **版本迭代**（高级技巧）：不换地图，让地图本身迭代（王朝末年→新朝建立→盛世→再崩坏），主角以家族/组织形式参与历史变迁

### 每张地图的循环结构

```
进入新地图 → 遇到初级对手 → 修炼突破 → 打脸初级对手
  → 中级对手出现(前者的兄长/师长)
  → 再修炼突破 → 打脸中级对手
  → 高级对手出现(世家高层/宗门强者)
  → 再再修炼突破 → 打脸高级对手 → 铺垫下一张地图的人际关系 → 换地图
```

## 章节循环（斗破式 120 章一个大阶段）

| 阶段 | 章节 | 内容 |
|------|------|------|
| 危机出现 | 1-10 | 主角因实力弱小面对危机，出现解决曙光和突破契机 |
| 积累成长 | 10-40 | 主角努力变强，修炼/炼丹/寻宝/获得机缘 |
| 初露锋芒 | 40-80 | 主角在当前舞台已有筹码，解决进一步危机 |
| 左右舞台 | 80-120 | 主角在此舞台举足轻重，危机妥善解决，开始进入下一舞台 |

## 突破写法

### 突破三要素

1. **突破前的压抑**：营造困境，让读者觉得"这次过不去了"
2. **突破瞬间的畅快**：天地灵气涌入、瓶颈碎裂、实力暴涨的画面感
3. **突破后的震撼**：周围人的震惊反应、对手的恐惧、新能力的初次展示

### 突破时机选择

| 类型 | 效果 | 说明 |
|------|------|------|
| 危机时刻突破 | 最爽 | 绝境中爆发，逆转战局 |
| 战斗后突破 | 合理 | 积累足够，战后感悟突破 |
| 闭关突破 | 平常 | 传统写法，需要搭配独特的突破条件 |

### 突破范例

```
✅ 轰！一声巨响，天地灵气疯狂涌入体内，金丹碎裂，一个小人从中走出——
元婴期！他终于突破了！
"不可能！他怎么会在这时候突破！"对手惊恐万状。
```

## 自检清单

| 检查项 | 不合格示例 |
|--------|-----------|
| 每个境界有独特叙事功能？ | 炼气到元婴只是数字变大，无新能力 |
| 换地图前铺垫了人际关系？ | 突然飞升到新世界，旧角色全弃 |
| 每级突破有难度/代价？ | 灵气够了自动突破 |
| 有"危机→积累→突破→震撼"的节奏？ | 突破后无任何反应直接下一章 |
| 战力体系没有崩坏？ | 筑基期秒杀化神期（无合理铺垫） |
