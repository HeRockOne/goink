# 反AI写作·用词级规则

> 与 `anti-ai-writing`（九条铁律，判定合格）互补。本 skill 提供具体到词的禁用表与频次阈值。

## T1 出现即换（0 容忍）

### 万能连接句（出现就换）
- ❌ 不是 A 而是 B
- ❌ 带着……
- ❌ 仿佛/犹如……一般
- ❌ 让/令/使 句式
- ❌ 当……时
- ❌ 他意识到/他感到/他注意到
- ❌ 与此同时

> 适用范围：以上句式作**万能连接或情绪标签**用时才换（如「这让我意识到……」「带着期待的心情，他推开门」「让他的内心久久不能平静」「当他站在门口时，他想起了往事」）。正常叙事中的自然用法不强制替换（如「让他愣了一下」「夜幕降临时分，城门已闭」偶发出现）——判定对象是高频模板动作，不是字面本身，与下方误杀防护同一原则。

### 一级禁用词
- 不禁/突然/瞳孔一缩/倒吸一口凉气/嘴角勾起一抹/心中涌起
- 显然/毫无疑问/坚定深邃冰冷/缓缓地/冷冷地

## T2 同段聚集才处理

- 然而/不过/此外/同时/虽然但是——同段出现 ≥2 次才替换

## T3 全文密度（超限即处理）

| 指标 | 阈值 |
|------|------|
| "了"字密度 | 平均每段 >2.5 个 |
| 句号密度 | 连续 10 句 |
| 段长均匀度 | 连续 5 段句子数差值 ≤1（太平整） |
| 突然 | ≤4 次/章 |
| 竟然/居然 | ≤3 次/章 |
| 渐渐/逐渐 | ≤2 次/章 |
| 似乎/也许/大概 | ≤3 次/500 字 |
| 破折号 | ≤3 次/章 |
| 同一情绪词 | 单章 ≤3 次 |

## 禁止结构

- 连续 4 句相同主语
- 连续 3 段相同开头
- 连续 5 句相同句式
- 禁句：「他不知道的是」「此时的他还不知道」「这一夜注定……」「从这一刻起……」

## 情绪外化替换表（标签句 → 感官证据）

| 情绪 | 替换 |
|------|------|
| 紧张 | 手抖/手心出汗/指节捏白 |
| 愤怒 | 青筋暴起/声音变轻/呼吸变重 |
| 害怕 | 手指碰到门把手又缩回/后颈发凉 |
| 悲伤 | 筷子停在半空/喉咙发堵/鼻尖发酸 |

## 反AI三遍法（润色流程）

- **Pass1 去泛化**：替换抽象套话（"心情复杂""深深震撼"），验证禁用词命中率下降 80% 以上
- **Pass2 去书面化**：去全知叙述、心理分析、内心辩论赛、副词修饰
- **Pass3 回自然感**：制造节奏起伏、加闲笔（无关紧要的细节）、加情绪反差；验证段落长度有自然变化 + 至少 1 处闲笔

## 误杀防护（防止过度去AI味）

以下**不替换**，保留：
- 角色的**专属口头禅**（人设的一部分，反复出现是对的）
- 对话中的情绪词（人物说话带"吓死我了"是正常的）
- 标点功能：破折号用于对话中断/思考延长是合理的（控制总量即可）
- 特定题材风格词（如古典仙侠的文言感、悬疑的冷峻感）——去 AI 味不能破坏风格基调

## 自检清单

1. 有没有 T1 万能句/禁用词？有 → 立即替换
2. T2/T3 阈值超限了吗？超 → 处理
3. 情绪词是标签还是感官证据？标签 → 用替换表
4. 三遍法都过了吗？卡在哪遍 → 重做该遍
5. 有没有误删角色口头禅/风格词？误删 → 恢复
