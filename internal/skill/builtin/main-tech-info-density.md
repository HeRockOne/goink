# 信息密度控制

## 核心规则

每300字必须有至少1个信息增量（新信息/新发展/新情绪）。

## 检查方法

将正文按300字分段，每段回答：这段提供了什么新信息？

- 如果答案是「没有」→ 该段需要修改或删除
- 如果连续2段无增量 → 删除其中一段

## 场景必要性

每个场景必须回答：这个场景存在是为了什么？

- 推进情节
- 展示角色
- 传递信息
- 营造氛围

如果一个场景不能回答以上任何一个问题 → 删除或合并到相邻场景。

## 信息增量类型

| 类型 | 示例 |
|------|------|
| 情节推进 | 发现关键线索/做出决定 |
| 角色揭示 | 展现性格/关系变化 |
| 世界观扩展 | 新设定/新规则 |
| 情绪变化 | 角色情绪转折 |
