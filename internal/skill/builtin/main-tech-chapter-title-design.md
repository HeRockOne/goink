# 章节标题设计

## 核心原则

标题是读者在目录里决定"要不要点开这一章"的最后一道筛选，它在功能上是产品设计——服务读者的点击欲望。但有两条底线不能破：**标题必须与正文相符**（标题党且内容空，番茄算法会降权，老读者会流失）；**关键反转不能剧透**（剧透是把结果告诉读者，钩子是亮身份和冲突不给答案）。先让标题真实反映本章核心事件，再谈吸引力。

## 铁律

1. **不剧透关键反转**——标题可以暗示，但不能说破（❌"凶手就是 B" ✅"他翻开日记的最后一页，上面画着一张和自己一模一样的脸"）
2. **连续 3-5 章同类型公式必须换**——避免目录节奏疲劳
3. **每章标题最后一句（或核心词）具备截图传播潜力**——让人看标题就想讨论
4. **前 30 章写完后把标题连起来读一遍**——检查节奏是否单一

## 平台适配

| 平台 | 标题字数 | 风格 |
|------|---------|------|
| 番茄 | 目录标题≤15字（手机端15-18字截断）；另设头条推荐标题15-30字 | 短句化、冲突化、身份化。核心信息放前12字 |
| 七猫/书旗 | 10-18字 | 同番茄，免费流量池吃短句冲突身份化 |
| 起点/QQ阅读 | ≤20字，可短至四字对仗 | 事件推进+主角状态，稳定写法；读者已订阅进目录，标题不用抢眼，太花哨反而显得浮躁 |
| 晋江 | ≤20字 | 含蓄，情感基调+景物意象。"梅雨夜的钢琴声"比"她哭了"好 |
| 飞卢 | ≤20字 | 脑洞化，标题本身就是脑洞的一部分 |
| 纵横 | 四字六字对仗 | 传统章回体，"雪落长安、剑指北疆"，玄幻历史尤其合适 |
| 刺猬猫 | ≤20字 | 吃梗吃角色称谓，可融入动漫术语 |

## 番茄头条推荐标题（独立字段，别浪费）

番茄有两个标题字段，独立填写：
- **目录标题**：目录里给读者看，15 字内留节奏悬念
- **头条推荐标题**：推荐到头条小说频道的推广字段，**15-30 字**，把卖点和当章冲突塞进去。签约作品专属，前 50 个免费章节可写，50 章后无效；可写数量由当日 10 万字读完率决定
- 其他平台（起点/晋江/飞卢/刺猬猫）都只有一个字段，不要把番茄这套搬过去

## 10种标题类型

### 1. 悬念留白型
**公式**：前半段陈述动作/场景 + 后半段戛然而止或指向不明关键词
**要点**：悬念词要具体。"惊天秘密"没用，"那张纸条上写着五个字"有用。具体的悬念才有画面感。
**正例**：师尊的剑落地了 / 老李头没有回来 / 我跟踪了老婆三天，发现她每晚十点去那栋楼
**反例**：事情有些不对劲（抽象，无画面）

### 2. 冲突画面型
**公式**：谁 + 做了什么 + 对谁。要有动作（撕/砸/掀/扇）、有对象、有场景。
**要点**：把最激烈的场景直接拍在读者脸上。适合爽文、玄幻、战斗章。
**正例**：他当着全场的面把合约撕了 / 老李头的门被踹开了 / 他只用了一招 / 全场安静，只有她的脚步声在响
**反例**：一场激烈的战斗（无画面、无冲突感）

### 3. 身份反转型
**公式**：暗示角色身份将发生颠覆性变化，但**不揭晓结果**——亮出线索或反差，把"他是谁"留给正文。
**要点**：每隔10-20章给一次大揭露。不能每章都揭，揭多了麻木。标题只亮冲突的开端，不让读者一眼看到反转的答案。
**正例**：清洁工捡到了创始人的工牌 / 他档案上写着"保密" / 原来他就是那个传说中的人 / 没有人知道，那个扫地的老头是剑圣
**反例**：他的身份不简单（太泛，无具体画面）

### 4. 对话片段型
**公式**：把一句对话直接放进章节名。
**要点**：那句话本身要有戏。平淡的"我爱你"没用，"我等了你十年，等到今天结婚的人是别人"有用。一句话里要有矛盾、反转或情绪爆点。
**正例**：不签 / 回去等通知 / 你好
**反例**：他说了一句话（无信息量）

### 5. 数字具体型
**公式**：用具体数字替代模糊修饰。
**要点**：不要用整数。奇数和带零头的数字更有真实感。"500万"不如"473万"，"三天"不如"73小时"。番茄悬疑短篇尤其偏爱倒计时型标题。
**正例**：三日后搬走 / 距离她失踪还有6小时
**反例**：巨额财富（抽象）

### 6. 反常识型
**公式**：打破读者预期。把通常的对立面写进标题。
**要点**：反常识不是反逻辑。角色行为反差最有效——"那个最讨厌孩子的他，抱着婴儿哭了"。
**正例**：杀人犯在法庭上笑了
**反例**：不可思议的事情发生了（无具体反常）

### 7. 情绪爆点型
**公式**：把情绪高位压缩进标题，做热搜围观感。
**要点**：适合言情/虐文/高潮章。情绪必须是"顶点瞬间"而非状态描述。
**正例**：你从来就没把我当过朋友 / 她转身走进了雨里，始终没有回头
**反例**：他很伤心（标签句，无张力）

### 8. 命运转折型
**公式**：暗示一个不可逆的变化。
**要点**：适合关键转折/换地图/突破。变化必须不可逆才有分量。
**正例**：从今天起，世上再无陈尘 / 他推开那扇门，一切都不一样了
**反例**：他做了一个重要的决定（抽象，无画面感）

### 9. 信息炸弹型
**公式**：章末扔出一个无法忽略的信息，标题本身即悬念。
**要点**：适合悬疑/揭秘/信息差。信息要具体到读者无法忽视。
**正例**：信上只有一行字：你的亲生父亲，是上一任城主 / 他翻遍了所有记录，发现了一个名字——他自己
**反例**：他发现了一个秘密（太泛，无具体信息）

### 10. 长短交替型（元节奏）
**公式**：不单独使用，而是控制目录的视觉节奏。三个长标题后接一个4-5字短标题，或反过来。短标题适合气氛骤变或情绪爆发的章节——"雨停了""门开了""灯灭了"，三五个字胜过一长串铺垫。老读者会形成"看到短标题就赶紧点"的条件反射。长标题适合前情提示或人物揭秘，方便从目录翻看的读者快速回忆剧情。
**要点**：控制目录的视觉节奏，避免连续 5 章都是 8 字以上长标题。
**正例**：追 / 他只用了一招 / 全城戒严 / 没有人知道真相 / 师尊的剑落地了
**反例（禁用）**：把关键反转直接写进短标题（"凶手是B""他死了"），那会毁掉悬念——反转揭晓必须发生在正文。

## 5个具体改法（从"内容复述"改成"钩子"）

新手通病是标题写成内容复述（"第X章 决斗""母亲的意外"），对照这5条改：

1. **事件复述 → 情绪缺口**："母亲的意外" → "母亲留下的最后一条语音，只有六秒"（数字+载体+情感，读者追问"六秒里说了什么"）
2. **抽象名词 → 具体动作+具体物件**："决斗" → "他掀开桌布，剑鞘还在滴血"（动作+物件，血从哪来读者会追问）
3. **加身份或关系触点**："相遇" → "前世的杀父仇人，此刻是她的相亲对象"（"谁和谁相遇"不点破标题就废了）
4. **反差/颠覆认知的对撞词**："真相" → "那个救过她三次的男人，是她十年前亲手埋的"
5. **具体数字替代模糊修饰**："惊天秘密" → "照片有七个人，四个已经死了"

## AI 生成红线（重要）

1. **AI 直接定稿，不产备选**——标题要结合本章剧情和追读节奏判断，直接确定最佳标题写入。仅当用户明确要求参与选标题时才提供备选（auto 审批模式下自主拍板，不停下来让用户选）
2. **禁止批量模板化**——番茄 2026 年已把"滥用 AI 批量生成"列为核心整治品类，全靠 AI 生成的目录会被识别为低质信号。连续 5 章标题不可同一句式模板
3. **标题必须从本章真实事件提炼**——禁止为凑类型公式编造与正文无关的标题

## 标题生成工作流

1. **确定本章核心事件**——这一章发生的最关键的事是什么（来自大纲关键事件）
2. **提取关键词**——事件中的人、动作、物件、台词
3. **选类型**——根据平台和章节位置选择10种类型之一
4. **组装标题**——用关键词按类型公式组装，套用 5 个改法检查是否仍是"内容复述"
5. **检查**——字数符合平台上限？有画面感？揭一半藏一半？与前几章类型不重复？
6. **放入目录**——把连续5章标题放在一起读，检查节奏是否单一；写完前30章回头把标题连读一遍，连续三五章同公式立刻调整

## 写前 30 秒检查（动笔前）

1. 本章标题是 10 种里的哪种？和前 3 章重复吗？
2. 标题有没有剧透关键反转？有 → 揭一半藏一半
3. 标题单独看，读者会想点吗？

## 自查清单

| 检查项 | 不合格示例 | 合格标准 |
|--------|-----------|---------|
| 有画面感/具体感 | 他做了一个决定 | 他把合约撕了 |
| 揭一半藏一半 | 凶手是张三 | 他翻开日记最后一页 |
| 与前3章类型不同 | 连续4章悬念型 | 类型轮换 |
| 字数符合平台上限 | 沪城2500万人没人记得他（超番茄15字） | 三日后搬走 |
| 来自大纲关键事件 | 编造的华丽句子 | 章内关键事件/台词提炼 |
| 核心信息在前12字 | 那个晚上发生了一件改变他一生的事 | 不签 |
| 与正文相符 | 标题党且内容空 | 读完标题与正文对得上 |
| AI 直接定稿 | 产备选让用户挑（auto 模式下禁止） | 结合追读节奏直接拍板 |
