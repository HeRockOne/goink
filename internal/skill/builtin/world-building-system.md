# 世界观构建

## 核心规则

世界观必须有边界，不能无限扩展。每次扩展必须有叙事目的。

## 力量体系设计

| 要素 | 要求 |
|------|------|
| 等级划分 | 明确的3-5级，每级有质变 |
| 代价机制 | 能力使用必须有代价/限制 |
| 克制关系 | 存在相克，没有无敌能力 |
| 信息投放 | 不能一次性揭示，按剧情需要分批 |

## 信息投放节奏

- 第1-5章：暗示存在，不揭示规则
- 第6-15章：小范围展示，读者理解基础
- 第16-30章：系统性揭示，读者建立完整认知
- 第31章+：深度挖掘，读者发现隐藏规则

## 禁忌

- 禁止设定与已有剧情矛盾
- 禁止一次性揭示所有规则
- 禁止让主角突然获得新能力（无铺垫）
