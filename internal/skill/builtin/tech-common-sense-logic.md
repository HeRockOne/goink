# 常识逻辑检查

## 核心规则

场景自带物理/社会规则，角色行为必须自洽：

```
场景（环境约束）→ 身份（角色定位）→ 行为（具体动作）
                     ↓
             三者必须自洽，否则需要设定支撑
```

## 五门检查

| 门 | 硬约束（必须阻塞） | 软约束（记录偏离） |
|----|-------------------|-------------------|
| 主角能力 | 使用了设定中不存在的能力 | 已有能力的新应用方式 |
| 时间线 | 无过渡交代的位置/时间跳跃 | 时间跳跃但有交代 |
| 角色状态 | 已死角色复活；状态矛盾 | 性格渐变发展 |
| 伏笔弧线 | 到期伏笔被遗忘 | target_chapter需调整 |
| 世界观常识 | 行为违反场景默认约束且无设定支撑 | 场景细节可创作中丰富 |

## 判定逻辑

- 🔴 硬约束违规 → 停止创作，修正后再继续
- 🟡 软约束偏离 → 记录偏离，校准后继续
- 🟢 弹性空间 → 自由创作

## 关键原则

设定是铁轨，情节是火车。火车可以在铁轨上灵活变速变向，但不能脱轨。新能力觉醒需要合理铺垫，不能凭空出现。
