# 反重复机制

## 判定标准

| 重复类型 | 判定 | 动作 |
|----------|------|------|
| 句式重复 | 连续3句相同词/结构开头 | 修改至少2句开头 |
| 开篇重复 | 本章与前2章相同 | 换开篇技法 |
| 场景重复 | 连续2章同类型核心场景 | 换新场景 |
| 对话重复 | 本章与前2章对话模式相同 | 更换对话模式 |
| 情感重复 | 连续3章情感基调相同 | 调整情感曲线 |
| 钩子重复 | 章末与前2章相同 | 更换钩子技法 |

## 指纹系统

每章写完后用 edit 的 append 模式在 goink.md 末尾追加（只追加，不覆盖历史指纹）。
必须严格按照以下 Markdown 格式（每段之间必须有空行，否则渲染会合并成一行）：

```
### 第N章 标题

开篇：开篇技法描述

场景：场景类型与转换

情感：情感基调曲线

对白：对话模式特点

钩子：章末钩子类型

感官：感官通道使用
```

注意：
- 每段之间必须有一个空行（Markdown 段落分隔）
- 不允许用逗号或竖线将多个字段写在一行
- 不允许省略或合并任何字段
- 每章独立一个区块，与前章之间空一行

写作前读最近3章指纹，逐项比对，重复项本章必须换。
