# 三方情绪注入

> 情绪的具体"展示通道"见 `show-dont-tell`（本 skill 不再重复）。本 skill 专注"情绪的分布结构"。

## 诊断标准（符合即需注入）

- 功能报告体：全是「做了什么→看到什么」
- 感官单一：几乎只有视觉
- 无情感锚点：角色内心无波动
- 配件工具化：配角无独立情绪
- 社会反应流水账
- 节奏平直

## 三方机制

### 主角线·情感锚点

每章至少1个，写法：
1. 用身体反应代替直接写情绪（「他很伤心」→ 手停在半空）
2. 用具体物件触发情绪（母亲的茶杯、旧荷包、对方衣领上的一根头发）
3. 锚点必须有停顿感（3-5秒沉浸）
4. 情绪必须「藏」——表面平静，内在波动
5. 内心独白规则：**只写必要的，且必须承载新信息（自我认知/秘密/决定），每章不超过 2 处、每处不超过 200 字**。禁止为了"有独白"而凑一段
   - ✅ 他跪着没动。他知道，这一跪下去，就再也回不了头了。（短促、承载决定）
   - ❌ 他心想，这些年来的种种过往如潮水般涌上心头，那些曾经的美好与遗憾交织在一起，让他久久不能平静……（堆砌、无新信息）

判断准则：**心理描写交给身体和动作，不直接交给"他想"**。直接写内心是"转告"，用细节让读者自己读出来才是"展示"——克制型角色的心理活动应该是短句、断点、留白。

### 配件线·独立情绪轨迹

每个配件必须有独立情绪，不能只是工具：
- 追查者：固执中的无力感（手抖/沉默/冷笑）
- 被追查者：谨慎中的恐惧（多等一秒/回头看/试探）
- 普通人：善良中的无知（絮叨/愣神/手抖）

### 社会反应线·折射法

禁止「专家说…网友说…媒体说…」流水账。必须通过具体的人折射：
- 小饭馆/出租车/便利店的普通人议论
- 新闻主播的语气变化
- 评论区具体留言

## 写完自查

| 检查项 | 不合格示例 |
|--------|-----------|
| 情绪有没有交给身体/物件/环境？ | 「她感到心碎」直接写出 |
| 独白是否承载新信息、≤2 处、≤200 字？ | 大段心理描写凑字数 |
| 每个配角有独立情绪反应？ | 配角全程无表情地完成任务 |
| 社会反应通过具体的人？ | 「网友们纷纷议论」 |
