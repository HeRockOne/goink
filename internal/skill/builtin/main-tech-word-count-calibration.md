# 字数校准

## 核心规则

目标字数见 kernel 硬约束，段数根据内容密度灵活调整（通常30-55段），每段60-80字。

## 创作前分配

按节预分配字数：
- 开场（1-8段）：600字
- 发展（9-25段）：1200字
- 高潮（26-40段）：1200字
- 收尾（41-55段）：500字

## 创作中计数

每写5段自查一次字数。写到2000字时必须确认还有足够空间完成章节。

## 字数不足处理（一次扩到位，禁止挤牙膏）

- **先算缺口**：缺口 = min_words − 当前字数。按缺口 × 1.2 设定扩写目标（预留校验误差余量），一次补到 min_words + 100 字以上，避免二次校验不达标
- **一次 read 一次 edit**：read 全文 → 选定 2-3 个可扩展点（场景描写/对话回合/内心独白各选一处）→ 一次 edit 完成全部扩写。**禁止"扩 200 字 → 校验 → 再读 → 再扩"的挤牙膏循环**（每次循环 = read + edit + get_chapter_list 三次调用，缺口 800 字要循环 4 次以上，纯浪费）
- **集中扩写**：每个扩展点单次 ≥300 字，优先扩 2-3 个关键段；**禁止全文撒胡椒面**（每段加 50 字会稀释节奏且难以一次达标）
- **缺口大时加段**：缺口 > 当前字数 30% 时，增加一个完整场景段（补一段动作细节/对话回合/情绪转折），不是只扩现有段落
- **扩写内容要求**：扩的是信息/感官/张力增量（新细节、新反应、新转折），不是同义重复——把一句话拆成三句说算灌水，会被 review 打回
- 禁止在字数不足时调用 set_phase
