# 视角纯度与身份感知控制

## 核心规则

主角视角叙事时，只能写主角**当前身份 + 当前处境**下能获取的信息。任何超出主角认知范围的内容，一律禁止直接呈现。

## 信息边界判定（写前确认角色身份）

动笔前，为当前视角角色建立**信息权限表**：

| 信息渠道 | 该角色可用？ | 延迟 | 覆盖范围 |
|---------|------------|------|---------|
| 亲眼所见 | ✅/❌ | 即时 | 当前场景 |
| 亲耳所闻 | ✅/❌ | 即时 | 当前场景 |
| 他人告知 | ✅/❌ | 告知后 | 取决于告知者知道多少 |
| 书面/传讯 | ✅/❌ | 传递耗时 | 信件/情报范围 |
| 势力情报网 | ✅/❌ | 数天 | 该势力渗透范围 |
| 记忆/旧识 | ✅/❌ | 即时 | 过去经历 |
| 超感知（神识/法术） | ✅/❌ | 即时 | 感知半径 |

## 信息禁区（默认禁止，除非剧情明确突破）

- 其他角色的**内心想法**（只能通过对话/行为/表情暗示）
- **不在场事件**（主角不在时发生的事，禁止直接写过程）
- 主角**不可能获得**的信息（如「他不知道的是…」句式一律禁止）
- 未来事件（禁止预知式描写，除非是金手指设定）

## 身份突破机制（合法获取信息的方式）

当剧情需要主角知道某事时，必须**通过渠道突破**，不能直接跳越：

1. **接触突破**：主角与知情者接触，通过对话/交易/审问获取
2. **探查突破**：主角主动调查（翻查书信/潜入现场/跟踪）
3. **意外暴露**：对手失误/第三方泄密，让信息被动到达
4. **成长突破**：角色能力提升（如修炼神识）扩大信息半径

每次突破必须：①有获取动作 ②有信息来源 ③有可信度权衡（信息可能是假的/不完整的）。

## 视角越界判定

写完后逐句问：

1. 「主角此刻能知道这个吗？」——不能 → 删除或改写
2. 「这个信息是主角亲眼/亲耳/他人告知得来的吗？」——不是 → 补获取动作
3. 「我在写上帝视角吗？」——是 → 切回主角能感知的层面

## 允许的例外

- 章节开头的时间/地点交代（功能性文本，不属于信息泄露）
- 伏笔暗示（只写现象，不揭示因果，遵循 `foreshadow-cycle` 的"写现象不写为什么"）
- 角色通过行为/对话**推测**出的信息（标注为推测，不写成事实）
- 多线叙事中切换视角时，每段开头明确标注当前 POV 角色

## 禁令（直接违规句式）

- ❌「他不知道的是，背后的门正在缓缓打开」
- ❌「而此时，千里之外的城主府里，一场阴谋正在酝酿」
- ❌「她心里想：……」（除非该角色是当前 POV）
- ❌「所有人都在震惊，只有主角……」然后写主角看不到的细节
