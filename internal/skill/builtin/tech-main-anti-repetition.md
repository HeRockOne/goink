# 反重复机制

## 判定标准

| 重复类型 | 判定 | 动作 |
|----------|------|------|
| 句式重复 | 连续3句相同词/结构开头 | 修改至少2句开头 |
| 开篇重复 | 本章与前2章相同 | 换开篇技法 |
| 场景重复 | 连续2章同类型核心场景 | 换新场景 |
| 对话重复 | 本章与前2章对话模式相同 | 更换对话模式 |
| 情感重复 | 连续3章情感基调相同 | 调整情感曲线 |
| 钩子重复 | 章末与前2章相同 | 更换钩子技法 |

## 指纹系统

每章写完后在 goink.md 追加：
```
第N章：开篇=[类型] 对话=[模式] 场景=[类型] 情感=[基调] 钩子=[类型] 感官=[通道]
```

写作前读最近3章指纹，逐项比对，重复项本章必须换。
