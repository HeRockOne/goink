# 章末钩子设计

## 三条铁律

1. 章末不是结束，是开始——每章结尾指向未完成的动作
2. 钩子强度要有节奏——过渡章温和，高潮章强烈
3. 钩子必须兑现——暗示的事件下一章必须发生

## 六种钩子类型

| 类型 | 公式 | 适用 |
|------|------|------|
| 怪物睁眼 | 平静积累→突发异变→戛然而止 | 强悬念 |
| 命运倒计时 | 死线逼近→最后一刻→留下悬念 | 紧迫感 |
| 表情扭曲 | 角色表情异常→读者好奇原因 | 人际张力 |
| 翻墙出府 | 角色突破限制→读者想知道后果 | 冒险感 |
| 欠人情 | 角色接受帮助→读者期待回报 | 关系推进 |
| 荒诞幽默 | 意外转折→轻松收尾→期待后续 | 节奏调节 |

## 使用原则

- 过渡章用温和钩子，高潮章用强烈钩子
- 不能每章都是「怪物睁眼」级别
- 钩子必须在下一章兑现
