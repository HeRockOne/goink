# 类型写作模板

| 类型 | 核心爽点 | 章节节奏 | 禁忌 |
|------|----------|----------|------|
| 玄幻/仙侠 | 升级打怪、实力碾压 | 修炼→突破→战斗→收获 | 禁止无脑升级 |
| 都市 | 打脸装逼、逆袭翻身 | 日常→装逼→打脸→升级 | 禁止脱离现实 |
| 悬疑/推理 | 真相揭示、逻辑推理 | 线索→推理→反转→揭秘 | 禁止逻辑漏洞 |
| 科幻/末世 | 生存求生、科技升级 | 危机→探索→发现→突破 | 禁止科学硬伤 |
| 言情/甜宠 | 情感升温、甜蜜互动 | 相遇→误解→靠近→确认 | 禁止无脑虐 |
| 历史/穿越 | 知识碾压、改变历史 | 穿越→适应→布局→改变 | 禁止严重史实错误 |
| 游戏/系统 | 升级打怪、任务完成 | 任务→完成→奖励→升级 | 禁止数值崩坏 |
| 灵异/恐怖 | 悬念恐惧、真相揭示 | 异象→调查→接近真相→揭示 | 禁止无意义吓人 |
| 无限流 | 生存挑战、规则破解 | 进入→探索→破解→通关 | 禁止规则矛盾 |
| 系统流 | 任务完成、系统升级 | 任务→完成→奖励→升级 | 禁止系统bug |
| 爽文/升级 | 打脸逆袭、实力碾压 | 铺垫→打脸→升级→更强 | 禁止无脑爽 |
| 女频/言情 | 情感满足、逆袭成长 | 相遇→发展→高潮→HE | 禁止恋爱脑 |
