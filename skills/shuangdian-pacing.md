# 爽点分级与节奏控制

网文的节奏本质是"给读者奖励的频率"。平路走超过 3 章，追读就开始掉。

## 爽点四级（量化设计）

| 级别 | 频率 | 示例 |
|------|------|------|
| **小爽点** | 每章 ≥1 个 | 小冲突小化解/小小的成长/一个甜头 |
| **中爽点** | 每 3-5 章 1 个 | 完整打脸流程/关系突破/实力跃升/谜题揭晓 |
| **大爽点** | 每卷 1 个 | 卷 Boss 战逆转/身份曝光连锁/多伏笔同时回收 |
| **超爽点** | 全书节点 | 改变格局的关键反转 |

## 爽点公式

```
铺垫（压抑感）→ 触发（爆发点）→ 释放（爽感）→ 余韵（反应/评价）
```

- 关键：铺垫越充分，释放越过瘾
- 不要急着爽，先让读者憋着
- 释放时放大旁观者的惊叹（迪化：敌我角色都不知道主角的妙计）

## 爽点类型（不能连续 5 章同类型）

打脸爽/装逼爽/逆袭爽/暴富爽/护短爽/身份揭秘爽/成长突破爽/收服爽——轮换使用。每章都爽但类型不同，读者不会腻。

## 甜虐比表（按题材设定）

| 题材 | 甜虐比 |
|------|--------|
| 甜宠文 | 9:1 |
| 爽文 | 8:2 |
| 虐文 | 3:7 |
| 悬疑 | 4:6 |
| 玄幻仙侠/都市 | 7:3 |
| 女频言情 | 6:4 |

## 张弛规则

- 紧张后必有放松，放松后必有紧张——不能连续 3 章同节奏
- 大爽点前要有铺垫（欲扬先抑）
- 情感高潮后要有余韵（禁顶点后大段独白）

## 钩子 7 型轮换（章末，不能连续 3 章同类型）

| 类型 | 示例 |
|------|------|
| 悬念钩 | 「门推开，进来的人让所有人都变了脸色——」 |
| 危机钩 | 「他以为结束了。但真正的麻烦，才刚刚开始。」 |
| 情绪钩 | 「她转身走进雨里，始终没有回头。」 |
| 信息钩 | 「信封里只有四个字：你父未死。」 |
| 选择钩 | 「摆在他面前的两条路，无论选哪条，都通向深渊。」 |
| 行动钩 | 「他握紧剑，走向那道从未有人活着离开的门。」 |
| 反差钩 | 「全场都在欢呼胜利，只有他脸色惨白。」 |

- 轮换顺序：悬念→危机→情绪→信息→选择→行动→反差
- 每章结尾最后一句**单独成段**，具备截图传播潜力

## 节奏模板（对照 book-outline 章节类型）

- **起承转爽**（最通用）：起 500 字回顾+冲突 → 承 800 字升级 → 转 300 字转折 → 爽 400 字反击 + 钩子
- **过山车**（战斗章）：紧张 → 缓 → 更紧张 → 以为结束 → 最紧张 → 结束+钩子
- **信息揭露递进**（悬疑/解谜）：线索A → 推理结论1 → 不对劲 → 线索B推翻 → 新推理 → 更大秘密

## 节奏硬约束

- ❌ 连续 3 章无高潮（追读开始掉）
- ❌ 铺垫最长不超过 2 章（大爽点需 5 章铺垫时，期间必须穿插小爽点）
- ❌ 全程匀速（AI 最大问题是"太均匀"，必须主动加速/减速）
- ✅ 紧张段落用短句（每句 ≤15 字），平静段落正常长句

## 自检清单

1. 本章有爽点吗？类型和前 5 章重复吗？
2. 大爽点铺垫够吗？中间有没有小爽点撑着？
3. 甜虐比符合题材吗？
4. 钩子是 7 型里的哪种？和前 2 章重复吗？
5. 节奏有快慢变化吗？还是匀速？
